# スピ系チェッカー

お酒を頼んだ時にタップして、豆知識を読みながら飲める記録アプリです。

## できること

- お酒と食べ物を、頼んだ時にタップするだけで記録
- 純アルコール量・カロリーを自動で計算
- 体調と体重から「何時にアルコールが抜けるか」の目安を表示
- 次の日の仕事の時刻に残りそうなら警告
- お酒・料理の豆知識（初級者・中級者・上級者・達人・変人の5段階）
- お店のタイプ別の料理とお酒の取り合わせ
- カレンダーで週・月の飲酒量と休肝日を集計
- 体重と飲み食いの関係を見る「ツミとバツ」
- Excel・CSVへの書き出し、バックアップと復元

## データの扱い

記録はすべて使っている人の端末（ブラウザ）の中だけに保存されます。サーバーには何も送りません。

## ご注意

- 20歳未満の飲酒は法律で禁止されています。飲酒運転は絶対にやめましょう
- 数値は一般的な目安から計算した推定値で、医療上の助言ではありません
- 運転や仕事をしてよいかの判断には使わないでください

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（1ファイルで動きます） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | 電波がなくても開けるようにする仕組み |
| `icon.svg`・`icon-*.png` | アイコン |

## 公開のしかた

Cloudflare Pages でこのリポジトリを接続し、ビルドの設定は空欄のまま公開します。
